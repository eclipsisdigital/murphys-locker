# Nieblas — archivo de terror psicológico

Landing page editorial en español, inspirada en la niebla, la señal analógica y el terror psicológico asociado a la saga *Silent Hill*.

## Abrir

Abre `index.html` directamente en un navegador moderno. La interfaz no requiere servidor ni proceso de build.

## Incluye

- Diseño responsive para escritorio, tablet y móvil.
- Hero atmosférico construido con CSS (sin imágenes externas).
- Archivo de juegos con filtros por tema.
- Expedientes modales para Silent Hill 1, 2 y 3.
- Navegación móvil, navegación suave y soporte para `prefers-reduced-motion`.
